# 代码参数修改指南

## 一、修改左侧边栏的宽度，同时不遮挡右侧内容

### 1. 点击 style.css

### 2. Ctrl + F，搜索以下类名

| 类名                               | 要修改的那一行内容             | 说明                                                      |
| ---------------------------------- | ------------------------------ | --------------------------------------------------------- |
| `.sidebar`                       | `width: 270px;`              | 侧边栏展开时的宽度，修改此值                              |
| `.home-section`                  | `left: 260px;`               | 主内容区距离左侧的距离，应设置为 `(sidebar宽度 - 10px)` |
| `.home-section`                  | `width: calc(100% - 260px);` | 主内容区宽度，`calc` 中的数值应与 sidebar 宽度一致      |
| `.sidebar .profile-details`      | `width: 260px;`              | 侧边栏底部个人信息区域宽度，应与 `left` 值一致          |
| `.sidebar.close`                 | `width: 78px;`               | 侧边栏收缩时的宽度（通常无需修改）                        |
| `.sidebar.close ~ .home-section` | `left: 78px;`                | 侧边栏收缩时主内容区位置（通常无需修改）                  |
| `.sidebar.close ~ .home-section` | `width: calc(100% - 78px);`  | 侧边栏收缩时主内容区宽度（通常无需修改）                  |

### 修改示例（将侧边栏从 270px 改为 320px）

| 类名                          | 原值                           | 修改为                         |
| ----------------------------- | ------------------------------ | ------------------------------ |
| `.sidebar`                  | `width: 270px;`              | `width: 360px;`              |
| `.home-section`             | `left: 260px;`               | `left: 360px;`               |
| `.home-section`             | `width: calc(100% - 260px);` | `width: calc(100% - 360px);` |
| `.sidebar .profile-details` | `width: 260px;`              | `width: 350px;`              |

### 注意事项

- 四个数值必须保持对应关系，否则会出现布局错位
